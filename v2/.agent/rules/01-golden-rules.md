# 01 Golden Rules

1. No edits to `v1/`; it is read-only.
2. Nothing created outside `v2/`.
3. No temp files in the repo (use `tempfile` or `cache/` or `outputs/`).
4. Never delete user files.
5. Never disable or weaken a test to make it pass.
6. Never claim something works without running it.
7. No `print()` in `src/` (use logging).
8. Commit after every completed task with a descriptive message.
9. Keep the repo root clean.
