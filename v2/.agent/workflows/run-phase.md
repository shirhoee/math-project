# Run Phase Workflow

For each phase:
1. Read status in `docs/04_PHASES_AND_STATUS.md`.
2. Read the phase's section in docs.
3. Implement the requirements.
4. Test thoroughly.
5. Run quality gates.
6. Update docs (`04_PHASES_AND_STATUS.md`, `CHANGELOG.md`).
7. Commit changes.
8. Move to the next phase.
