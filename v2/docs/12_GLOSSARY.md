# 12 Glossary

- **Intrinsics (K):** Camera matrix relating 3D points to 2D image coordinates.
- **Extrinsics (R, t):** Camera pose representing rotation and translation.
- **Homography:** A 2D projective transformation mapping points from one plane to another.
- **Adjugate Matrix:** The transpose of the cofactor matrix, used to find inverses without full linear algebra solvers.
- **MPI (Multi-Plane Image):** A representation using multiple parallel planes of RGB-Alpha images.
- **Disparity:** Inverse depth.
